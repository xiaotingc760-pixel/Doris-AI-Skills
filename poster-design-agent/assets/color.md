# 色彩规范建议

此文件提供通用设计框架，正式项目以品牌 VI 为准。

## 色彩角色

- Brand Primary：品牌主色
- Brand Secondary：品牌辅助色
- Accent：CTA／强提醒
- Text Primary：主文字
- Text Secondary：次级文字
- Background：背景
- Surface：卡片／容器
- Success：成功
- Warning：警告
- Error：风险／错误

## 使用规则

- 一个页面只保留一个主要强调色
- CTA 与背景必须形成明显对比
- 大面积高饱和色谨慎使用
- 金融科技项目避免通过金色、红色、钞票元素暗示高收益
- 活动页可用渐变，但不得影响文字可读性
