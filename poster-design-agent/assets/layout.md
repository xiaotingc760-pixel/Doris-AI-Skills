# 布局与栅格建议

正式尺寸以渠道规范为准。

## 常用布局

### 左文右图
适合：产品 Banner、数码产品推广

### 上文下图
适合：移动端海报、App 活动页

### 中心聚焦
适合：新品首发、品牌型 KV

### 卡片式
适合：权益说明、金融产品信息、App 运营页

## 栅格原则

- 建议使用 4 / 8pt 基础间距体系
- 同一级别模块保持统一间距
- 主内容不贴边
- 重要文字避开异形屏、圆角与裁切区
- 多尺寸适配时优先保证：主标题、产品、CTA 三者不丢失

## 阅读路径

推荐：

主标题 → 产品／利益点 → 辅助信息 → CTA → 规则／品牌
