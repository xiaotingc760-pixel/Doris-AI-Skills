# 多场景设计规范

仅加载当前任务涉及的场景。

## 1. 电商促销 Banner

目标：快速传达活动利益点并推动点击。

推荐结构：

1. 活动主标题
2. 核心利益点
3. 产品主视觉
4. 价格／优惠信息
5. CTA
6. 活动规则入口

重点：

- 利益点必须可验证
- 价格信息需要明确适用条件
- 不让装饰元素抢占商品主体

## 2. 数码产品推广

目标：突出产品价值与科技感。

推荐结构：

- 产品大图
- 一条核心卖点
- 2～3 个辅助参数
- 使用场景
- CTA

重点：

- 产品外观真实
- 参数不得编造
- 不使用不存在的功能演示

## 3. App／小程序运营页

目标：提升任务理解与点击效率。

推荐：

- 首屏一个核心动作
- 视觉焦点集中
- CTA 固定或明显
- 重要规则可快速展开
- 适配不同机型安全区

## 4. 小红书封面

目标：提高信息流点击。

推荐：

- 4～8 字主标题
- 强视觉主体
- 高对比
- 适度人物／产品关系
- 避免过多小字

不建议：

- 模拟平台官方认证样式
- 夸张收益或虚假前后对比

## 5. 金融科技营销

目标：建立信任、解释产品、推动合规转化。

推荐：

- 明确服务主体
- 核心功能
- 适用对象
- 关键条件
- CTA
- 必要说明

视觉上避免：

- 现金雨
- 暴富
- 保证收益
- 无风险暗示
- “人人可得”的审批暗示

## 6. 分期购机／租赁

必须先区分：

- 商品分期
- 信用支付
- 消费贷款
- 经营租赁
- 融资租赁
- 租完即送

画面应清楚说明：

- 用户拿到什么
- 谁提供服务
- 是否取得所有权
- 月付／总价／期数等条件如何适用

不得使用模糊视觉让贷款看起来像普通商品折扣。
