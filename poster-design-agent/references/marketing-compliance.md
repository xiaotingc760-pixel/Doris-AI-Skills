# 营销合规规范

> 本文用于设计执行中的风险识别，不替代企业法务、合规负责人、监管规则或投放平台最终审核。

## 1. 基本原则

营销视觉必须做到：

- 事实可验证
- 主体可识别
- 条件可理解
- 风险不隐藏
- 不制造错误预期
- 不伪造授权、资质或背书

## 2. 高风险信息

以下信息必须有明确业务依据：

- 价格
- 折扣
- 赠品
- 返现
- 月供
- 利率
- 费率
- 额度
- 期数
- 免息
- 0 首付
- 审批结果
- 到账时间
- 商品所有权
- 活动资格
- 销量
- 排名
- 用户评价
- 官方合作
- 监管资质

## 3. 金融类禁止或高风险表达

不得无依据使用：

- 100% 通过
- 秒批
- 必下款
- 0 风险
- 无门槛
- 人人可贷
- 保本
- 稳赚
- 官方指定
- 国家背书

如业务确有相应条件，仍需按实际法规、平台与法务要求展示限定条件。

## 4. “0 元／免费／免息”

必须确认：

- 是否真的没有支付义务
- 是否仅首期 0 元
- 是否需要押金
- 是否有服务费
- 是否有附加条件
- 是否存在期末买断
- “免息”是否仍有其他费用

如果条件复杂，主视觉不得用极大字号突出“0”而把限制条件缩成不可读脚注。

## 5. 租赁与分期

不得通过设计混淆：

- 租赁与购买
- 分期与贷款
- 月租与月供
- 商品价格与融资总成本
- 所有权与使用权

## 6. 品牌与素材

使用 Logo、品牌名、人物肖像、IP、产品素材前确认权利来源。

禁止：

- 伪造联合品牌
- 擅自改变 Logo 结构
- 使用无授权明星肖像
- 生成“看起来像官方合作”的虚假视觉

## 7. 数据与隐私

展示用户数据、交易信息、订单、银行卡、手机号等时必须脱敏或使用虚构演示数据。

真实截图进入公开物料前应确认：

- 是否脱敏
- 是否取得授权
- 是否包含账号、订单、证件等敏感信息

## 8. 审核结论

统一输出：

### 通过
无明显阻塞项，可进入正常业务审核。

### 有条件通过
设计方向可用，但仍有少量事实或素材需要确认。

### 阻塞
存在无法继续的关键缺失或明显风险。

### 需法务复核
涉及金融条件、监管敏感、复杂授权或其他超出设计审核能力范围的问题。
