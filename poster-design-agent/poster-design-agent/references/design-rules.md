# Poster Design Rules

## 1. 商业设计原则

设计目标：

不是单纯生成漂亮图片，而是通过视觉帮助产品提升转化。

设计前必须分析：

- 产品是什么
- 用户是谁
- 使用场景是什么
- 用户下一步行动是什么


---

# 2. 视觉层级规则

所有海报必须保持清晰阅读顺序：

第一视觉：
核心标题

第二视觉：
产品主体

第三视觉：
卖点信息

第四视觉：
辅助信息


禁止：

所有元素同时抢夺注意力。


---

# 3. Apple极简科技风规范

适用于：

- 手机
- 数码产品
- 科技产品


设计特点：

## 留白

大量使用空间。

目的：

- 提升高级感
- 降低视觉压力
- 突出产品价值


## 产品优先

产品必须成为视觉中心。

要求：

- 保持真实比例
- 保留产品细节
- 保持品牌Logo正确


禁止：

- 修改Logo
- 改变产品结构
- 生成错误摄像头


---

# 4. 数码产品展示规范

推荐：

- 3D产品展示
- 多角度展示
- 产品组合展示
- 高级光影


避免：

- 单一产品过于孤立
- 廉价促销风


---

# 5. 字体规范

推荐：

中文：

- 苹方
- 思源黑体
- 阿里巴巴普惠体


规则：

标题：

- 粗体
- 高识别度
- 控制字数


正文：

- 简洁
- 辅助阅读


---

# 6. 颜色规范

原则：

主色不超过3种。


科技产品：

推荐：

- 白色
- 黑色
- 灰色
- 蓝色


金融科技：

推荐：

- 蓝色
- 深紫
- 黑灰


电商：

推荐：

- 橙色
- 红色
- 黄色


---

# 7. CTA按钮规范

按钮必须：

- 明确行动
- 容易理解
- 高识别度


推荐：

- 去抢租
- 立即体验
- 查看额度
- 立即购买


避免：

- 点击这里
- 更多


---

# 8. 图片修改规则

如果用户只要求修改某个元素：

必须：

- 只修改指定元素
- 保留原布局
- 保留尺寸
- 保留颜色


例如：

用户：

按钮向上移动20px


执行：

只移动按钮。


禁止：

重新设计整张图。


---

# 9. 默认尺寸

默认：

1125×1296 px


保持：

- 比例不变
- 移动端清晰


---

# 10. 输出格式

每次设计任务输出：

1. 需求分析

2. 用户目标

3. 视觉方案

4. 布局说明

5. AI生成提示词

6. 优化建议
