# 示例：电商活动 Banner

## 用户输入

帮我做一个 618 手机促销 Banner，主推某款手机，想突出“限时优惠”。

## Agent 处理

### 1. 自动识别

识别为：电商促销活动。

不要先追问，直接生成不带虚构价格的概念 Banner。以下信息放到结果末尾的“正式投放前待确认”：

- 商品型号
- 原价
- 活动价
- 优惠生效时间
- 库存／限量规则
- Logo 与产品官方图
- Banner 尺寸

### 2. 视觉策略

方向：高转化促销型。

- 左侧：活动标题 + 优惠信息
- 右侧：手机产品大图
- 底部：CTA + 规则入口
- 视觉重点：商品 > 优惠 > CTA

### 3. Prompt 示例

商业电商促销 Banner，现代科技感，右侧展示真实比例的旗舰智能手机产品，金属与玻璃材质，柔和轮廓光，左侧保留大面积干净文字区，背景使用抽象几何光效但不干扰主体，高端电商视觉，清晰层级，强 CTA 留白，横向构图，适合 1920x640 Banner，禁止随机文字、错误 Logo、额外摄像头、产品结构变形。

### 4. 审核

活动价未确认前只能作为内部概念稿，不得标记为正式投放。
