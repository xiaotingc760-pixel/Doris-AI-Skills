# 示例：小红书封面

## 用户输入

帮我做一张“小白选手机避坑指南”的小红书封面。

## 设计方向

业务类型：普通内容营销，不涉及金融或价格促销。

目标：提升信息流点击。

### 文案

主标题：
小白选手机
避坑指南

辅助标签：
参数｜预算｜场景

### 布局

- 上部：主标题
- 中部：1 台手机主视觉
- 侧边：3 个简短标签
- 下部：账号／栏目识别

### Prompt

小红书科技数码封面，年轻、干净、可信赖，中心一台现代智能手机，浅色简洁背景，少量科技几何元素，高对比标题留白，竖版构图，信息流强识别，画面不生成具体中文文字，仅预留标题区域，避免夸张霓虹、错误品牌标识、产品结构畸变。
