# 示例：金融科技营销海报

## 用户输入

帮我做“手机月付 199 元起”的推广海报。

## 1. 直接处理

不要先追问完整业务关系。自动识别为“月付类高风险营销”，立即输出安全概念方向；由于“199 元起”缺乏适用条件，概念稿不把它作为最终承诺，改用“轻松用新机”或“查看月付方案”等中性文案。

## 2. 概念方向

直接输出不带未经确认金融条件的视觉结构：

- 顶部品牌
- 中部手机产品视觉
- 主标题占位
- 月付利益点占位
- 服务主体说明区
- CTA
- 条件说明区

## 3. 正式投放前待确认

在结果末尾集中列出：业务类型与服务主体、“199 元起”的适用机型和条件、用户是否取得所有权。不要在开场连续询问。
