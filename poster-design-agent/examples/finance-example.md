# 示例：金融科技营销海报

## 用户输入

帮我做“手机月付 199 元起”的推广海报。

## 1. 强制业务确认

仅凭“月付”无法判断业务类型。

必须确认：

- 是商品分期、消费贷款、信用支付还是租赁
- 实际服务提供方
- 资金方
- 期数
- 是否有首付
- 是否有手续费／利息
- “199 元起”的适用机型与条件
- 用户最终是否取得手机所有权

## 2. 阻塞规则

上述关键条件未确认前：

- 不输出正式投放稿
- 不把“199 元起”设计成最终承诺
- 不使用“0 利息”“无门槛”等文案

## 3. 可做的概念方向

可以先输出不带真实金融条件的视觉结构：

- 顶部品牌
- 中部手机产品视觉
- 主标题占位
- 月付利益点占位
- 服务主体说明区
- CTA
- 条件说明区

## 4. 审核结论

当前状态：阻塞。

原因：金融业务关系、月付条件与所有权信息未确认。
